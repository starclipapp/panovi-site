## 書ける材料（アプリにある機能）

記事に書く前に、まだアプリにあるか・名前が変わっていないかを確かめる。

| 機能 | 画面の言葉（ja） | 使える記事 |
|---|---|---|
| QRで2台をつなぐ（iOS 18以降・Apple ID不問・ネット不要） | グループを作る／QRを読み取る／カメラにする | 入門・借りる |
| 左右の担当を選ぶ | 自分の担当をタップで選択 | 入門 |
| 置き方の確認・3秒の確認（無料） | 配置を確認／3秒で動きを確認 | 置き方・運動会 |
| 2台で使えるレンズを自動で選ぶ（違う機種でも可） | 2台で使えるのは…だけです | 入門・借りる |
| 録画の長さに制限なし・省エネ（画面を消す） | 録画中の省エネ | 試合・旅行 |
| 3台目のリモコン（開始・停止・つなぎ目の確認・電池と容量・取り寄せ） | リモコンにする／リモコンを追加 | 試合・リモコン |
| 結合（重なりで位置合わせ・色と明るさをそろえる・4Kのまま） | 撮影を結合する／カメラロールに保存 | 入門 |
| まとめて結合 | すべて結合して保存 | 試合 |
| やり直し（区切り直し・別の方法・継ぎ目の色の合わせ方） | 結合をやり直す／継ぎ目の色の合わせ方 | 置き方・うまくいかないとき |
| 寄って見る（ダブルタップ拡大・ドラッグ） | ダブルタップで拡大・ドラッグで動かせます | 入門・寄って見る |
| YouTube 用の書き出し（8K／8K＋VR） | YouTube 用に書き出し | YouTube |
| 容量の管理（アプリ内の確認用動画・古いキャッシュを消す、空き容量の表示） | この端末の動画 | 容量 |
| 1台モード（広角＋超広角、撮影中ズーム、ズームの記録・あとから直す） | 1台で撮る／ズームで見る／撮影時のズームに戻す | 1台 |
| サンプル動画（2台そろう前にできあがりを見る） | — | 入門 |
| 料金（撮影・転送・確認・3分未満は無料、3分以上は無料3回→イベント券／買い切り） | イベント券を使う／買い切りで無制限 | 試合・料金 |
| オファーコード | コードを使う | お知らせ |
| アプリの言語（日・英・葡・西） | — | お知らせ |
| panovi viewer（ブラウザで YouTube / mp4 を寄って見る） | — | 寄って見る |

## 記事を出したあとに見るもの

- Google Analytics: 記事ごとの閲覧数と `appstore_click`（記事 `post` と言語 `lang` つき）
- Search Console: 記事ごとの検索語。よく来る検索語は次の記事の題やリードに使う
- App Store Connect: 公開した週のダウンロード数（App 分析 → 参照元）
